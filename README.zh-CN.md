# 不可能车站

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

一件可以玩的微型作品：选择站台，扳动道岔，让一列小火车穿过四个不可能的世界。收集四枚车票后，地图会出现第五站，等待你为它命名。

所有插画均由代码绘制。作品可以离线运行，不需要安装依赖、外部素材、账号或追踪服务。

## 打开车站

用浏览器打开以下任一独立文件：

| 文件 | 初始语言 |
| --- | --- |
| `不可能车站.html` | 简体中文 |
| `impossible-station.html` | English |
| `impossible-station-ja.html` | 日本語 |

每个文件都包含完整应用。通过语言选择器切换语言，会保留当前旅程、手记和自定义站名。

也可以直接打开源文件入口 `dist/index.html`。它按浏览器语言选择初始界面：`zh` 使用中文，`ja` 使用日语，其他语言使用英语。

如果需要本地 HTTP 预览，在项目目录运行：

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

访问 `http://127.0.0.1:8765`；结束后按 **Ctrl+C** 关闭服务。

## 开始旅行

- 选择折纸海、倒置果园、月亮修理铺或未寄出的城。列车可以随时发车、暂停或继续。
- 换轨会选择下一站。运行中选择新目的地，只改变下一班列车，并优先于自动漫游的推荐。
- 「盲选」和「自动漫游」优先探索尚未抵达的站点。可在 **1×、2×、4×** 之间切换；完整往返需要 20 个模拟秒。
- 切换到车窗视角，欣赏各站不同的移动风景。车窗始终显示本班列车的目的地，即使已为下一班改道。
- 打开车票夹，阅读旅途故事和纪念物。抵达第五站后，可以在其中为它命名。
- 在旅途手记中为每个已到访的车站留下感想，每篇最多 160 个 Unicode 码点。首次抵达和到访次数会在本次旅程中记录。
- 导出 **1200 × 800 的 SVG 明信片**，保存站点图案、故事、纪念物、感想和到访记录。感想可以留空；导出文字中的连续空白会合并。

打开车票夹会暂时暂停正在运行的列车，关闭后恢复。页面转入后台时旅程暂停，返回后继续，不会把离开期间的时间计入旅程。

| 按键 | 操作 |
| --- | --- |
| `1`–`4` | 选择目的地 |
| `5` | 解锁后选择第五站 |
| `Space` | 发车、暂停或继续 |
| `R` | 换轨 |
| `V` | 切换线路图与车窗 |
| `M` | 开关声音 |

## 调整观看方式

界面支持**浅色、深色和跟随系统**，默认跟随系统，并在页面打开期间响应系统外观变化。铁路插画保留夜景，导出的明信片保留纸质配色。

声音默认关闭。点击 **≈** 可以减少装饰动效，初始设置跟随系统偏好；列车和行程进度仍然正常工作。后台页面同时暂停模拟和声音。

进度、手记、站名、语言和主题选择只保存在当前页面内存中。刷新会开始新旅程，喜欢的明信片请先导出。应用没有外部网络请求，不使用 Cookie 或持久化浏览器存储。

## 开发与检查

只有构建和自动检查需要 Node.js，不需要安装额外软件包。

```sh
node check.mjs
node regression.mjs
node journal-check.mjs
node preferences-check.mjs
node build.mjs
node verify-build.mjs
```

构建脚本生成三种语言的独立 HTML 文件。检查脚本在模拟 DOM 环境中运行实际应用脚本，覆盖行程计时、换轨、收藏、手记、明信片生成和偏好设置。构建后，`verify-build.mjs` 检查三个版本的默认语言、内嵌源码一致性、无外链脚本及脚本语法。

**验证范围：**这些是模拟与结构检查，不是真实浏览器验收。实际浏览器中的画面布局、文件下载和声音播放尚未验证；SVG 内容检查也不能代替打开导出图片进行视觉检查。

## 文件结构

| 路径 | 用途 |
| --- | --- |
| `dist/` | 应用源文件：HTML、CSS 和 JavaScript |
| `build.mjs` | 打包三种语言的独立文件 |
| `check.mjs` | 核心交互和状态检查 |
| `regression.mjs` | 计时、绘制和布局几何回归检查 |
| `journal-check.mjs` | 手记与 SVG 导出检查 |
| `preferences-check.mjs` | 语言与主题检查 |
| `verify-build.mjs` | 构建后的独立文件检查 |
| `test-artifacts/` | 检查时生成的样本（如有） |
| `README*.md` | 英文、中文和日文说明 |

所有地点和故事纯属虚构。这里不需要寻找最短路径，每一条绕路都算数。
