# ありえない駅 — The Impossible Station

> 本作は、自由な創作依頼を受けて ChatGPT が発案・実装した小さな創作実験です。着想はユーザーの個人的な関心や経歴に基づくものではなく、リポジトリ所有者の見解や研究を示すものでもありません。

[English](README.md) · [简体中文](README.zh-CN.md) · [日本語](README.ja.md)

存在しない場所へ向かう、小さな鉄道のインタラクティブ作品です。行き先を選び、夜の世界へ列車を送り出して、各駅の切符を集めます。4枚そろうと5番目の駅が現れ、その駅に自分で名前を付けられます。

すべてのイラストをコードで描画しています。インストール、外部素材、アカウント、トラッキングは不要で、オフラインで動作します。

## 駅を開く

オンラインで遊ぶ：[ありえない駅](https://wangyouyue.github.io/impossible-station/)。ブラウザーの言語で起動し、言語セレクターでも切り替えられます。

次のいずれかのファイルをブラウザーで開いてください。

| ファイル | 起動時の言語 |
| --- | --- |
| `impossible-station-ja.html` | 日本語 |
| `impossible-station.html` | English |
| `不可能车站.html` | 简体中文 |

どのファイルにもアプリ全体が含まれています。言語セレクターで切り替えても、進行中の旅、旅のメモ、自分で付けた駅名は保持されます。

ソース版の `dist/index.html` も直接開けます。ソース版の初期言語はブラウザーの言語に従い、`zh` なら中国語、`ja` なら日本語、それ以外なら英語になります。

必要に応じて、プロジェクトのディレクトリでローカル HTTP サーバーを起動できます。

```sh
python3 -m http.server 8765 --bind 127.0.0.1 --directory dist
```

`http://127.0.0.1:8765` にアクセスしてください。終了する際は **Ctrl+C** でサーバーを停止します。

## 旅のしかた

- 折り紙の海、さかさま果樹園、月の修理屋、出せなかった手紙の街へ。列車はいつでも発車、一時停止、再開できます。
- ポイントを切り替えて次の行き先を選びます。走行中の変更は次の列車に適用され、自動巡回よりも手動の選択が優先されます。
- おまかせ選択や自動巡回は、まだ訪れていない駅を優先します。速度は **1×・2×・4×**。往復にはシミュレーション内で20秒かかります。
- 車窓表示は**「いま、ここ」**のホームから始まります。発車後はホームから沿線の山野、目的地へと景色が徐々に移り変わり、帰りは同じ道をたどって始発駅へ戻ります。行き先を選んでも今の車窓は切り替わりません。一時停止すると移り変わりも止まり、動きを減らす設定ではスクロールせずフェードでつながります。
- 切符のコレクションを開くと、各駅の物語やお土産を読めます。5番目の駅に着いたら、そこで駅名を付けられます。
- 訪れた駅ごとに、Unicodeコードポイントで最大160字のメモを残せます。初めて到着した便と訪問回数も、現在の旅の間は記録されます。
- **1200 × 800 の SVG ポストカード**を保存できます。駅のイラスト、物語、お土産、メモ、訪問記録が入ります。メモは空欄でも構いません。書き出した文章では連続する空白をまとめます。

コレクションを開くと走行中の列車は一時停止し、閉じると再開します。ページがバックグラウンドに移った間も旅は停止し、戻るとその続きから再開します。

| キー | 操作 |
| --- | --- |
| `1`–`4` | 行き先を選ぶ |
| `5` | 解放後に5番目の駅を選ぶ |
| `Space` | 発車・一時停止・再開 |
| `R` | ポイントを切り替える |
| `V` | 路線図と車窓を切り替える |
| `M` | 音のオン・オフ |

## 表示と音の設定

外観は**ライト・ダーク・システム設定**から選べます。初期設定はシステム設定で、ページを開いている間の外観変更にも追従します。鉄道のイラストは夜景のまま、書き出したポストカードは紙の配色のままです。

音は初期状態ではオフです。**≈** ボタンで装飾的な動きを減らせます。初期設定はシステムの動きに関する設定に従います。動きを減らしても、列車と旅の進行表示は機能します。バックグラウンドではシミュレーションと音が停止します。

進行状況、メモ、駅名、言語、外観設定は、現在のページのメモリー内だけに保持されます。再読み込みすると新しい旅が始まるため、残したいポストカードは先に保存してください。外部へのネットワーク要求、Cookie、永続的なブラウザーストレージは使用しません。

## 開発とチェック

ビルドと自動チェックを実行するときだけ Node.js が必要です。追加パッケージのインストールは不要です。

```sh
node check.mjs
node regression.mjs
node journal-check.mjs
node preferences-check.mjs
node build.mjs
node verify-build.mjs
```

ビルドでは、3言語それぞれの単独で動作する HTML ファイルを生成します。チェックは実際のアプリケーションスクリプトを模擬 DOM 上で動かし、旅の計時、行き先の選択、コレクション、メモ、ポストカード生成、設定を確認します。ビルド後の `verify-build.mjs` は、各版の初期言語、埋め込んだソースの一致、外部リンクのスクリプトがないこと、スクリプトの構文を確認します。

**検証範囲：**これらは模擬環境と構造のチェックであり、実ブラウザーでの受け入れテストではありません。実際の画面レイアウト、ファイルのダウンロード、音声再生は未検証です。SVG の内容チェックも、書き出した画像をブラウザーで開いて確認する作業の代わりにはなりません。

## ファイル構成

| パス | 用途 |
| --- | --- |
| `dist/` | HTML、CSS、JavaScript のソース |
| `build.mjs` | 各言語の単独ファイルを生成 |
| `check.mjs` | 基本操作と状態のチェック |
| `regression.mjs` | 計時、描画、レイアウト座標の回帰チェック |
| `journal-check.mjs` | メモと SVG 書き出しのチェック |
| `preferences-check.mjs` | 言語と外観設定のチェック |
| `verify-build.mjs` | ビルド後の単独ファイルのチェック |
| `test-artifacts/` | チェックで生成するサンプル（存在する場合） |
| `README*.md` | 英語・中国語・日本語の説明 |

すべての場所と物語はフィクションです。最短ルートを探す必要はありません。寄り道も、旅の一部です。
